# 🎮 PlayVerse

Bienvenue dans **PlayVerse**, une plateforme web immersive qui regroupe des mini‑jeux rétro en ligne.  
Interface sombre animée, ambiance gaming, et une sélection de jeux fun comme **Build a Jetpack** et **Scrap Boy**.  

## ✨ Aperçu

PlayVerse est pensé comme un **hub de jeux rétro** avec une interface moderne et animée.  
Il est construit en **HTML / CSS / JavaScript** et déployé sur **Vercel**.

## 🚀 Fonctionnalités

- 🌌 Interface sombre animée avec particules pour une ambiance cyber/gaming.  
- 🕹️ Sélection de jeux via une page d’accueil interactive.  
- 📱 Responsive design : fonctionne sur PC, tablette et mobile.  
- 🔗 Lien direct vers PICO‑8 EDU pour créer vos propres jeux.  
- ⚡ Déploiement instantané sur Vercel.  

## 🕹️ Jeux disponibles

- 🚀 Build a Jetpack  
- 🤖 Scrap Boy  

## 🛠️ Technologies utilisées

- **HTML5** → structure des pages  
- **CSS3** → styles, animations, effets néon  
- **JavaScript** → particules animées et interactivité  
- **PICO‑8 EDU** → intégration des jeux rétro  
- **Vercel** → hébergement et déploiement
